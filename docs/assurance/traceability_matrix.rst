Traceability Matrix (Certification-Grade)
=========================================

Purpose
-------
This document summarises bidirectional traceability from LSIS-AFS and SW-SAF
requirements to design, implementation, tests, and evidence artifacts.

The canonical, machine-readable matrix is auto-generated by
``scripts/verify_traceability.py`` and stored at
``docs/assurance/private/traceability_matrix.rst`` (full detail) and
``docs/assurance/private/evidence/traceability.json`` (JSON form).

The ``traceability.yml`` CI workflow enforces that every ``[LSIS-AFS-*]`` and
``[SW-SAF-*]`` tag in the C++ source has a corresponding entry in the matrix.

Maintenance
-----------
- The CI ``traceability.yml`` workflow fails if any ``[LSIS-AFS-*]`` tag in
  source has no corresponding matrix entry.
- Update ``docs/assurance/private/traceability_matrix.rst`` for every new
  requirement or implementation change.
- This summary document is regenerated from the canonical matrix at each
  milestone review.

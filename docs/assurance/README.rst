Assurance Document Index
========================

Assurance and certification-support artefacts for the project.  The canonical
entry points:

- ``docs/assurance/mission_assurance.rst``: Mission assurance philosophy and
  hardening requirements.
- ``docs/assurance/c_plus_plus_guidelines.rst``: C++20 coding standard for
  certifiable flight software.
- ``docs/assurance/traceability_matrix.rst``: Canonical requirements-to-evidence
  traceability matrix.
- ``docs/assurance/tool_confidence.rst``: Toolchain confidence record for
  evidence artifacts.
- ``docs/assurance/build_policy.rst``: Flight vs non-flight build policy.
- ``docs/assurance/configuration_baseline.rst``: Release baseline and
  reproducibility guidance.
